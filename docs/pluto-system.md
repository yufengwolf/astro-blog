- Charon 直径约为冥王星的**一半**，轨道半径仅 19,591 km（约 16.5 倍冥王星半径）——相比之下月球轨道是地球半径的 60 倍。
- 两者互相潮汐锁定，系统**质心落在冥王星本体之外**，因此常被称作"双矮行星系统"。
- 4 颗小卫星与 Charon 成 **1:3.16 / 1:3.89 / 1:5.04 / 1:5.98** 的近共振链，轨道近圆且几乎共面（倾角 < 1°），很可能是同一次大撞击的碎片。
- 切到「五颗卫星全览」档可一次看到全部；冥王星自转轴倾角 122.53°，也是倒着自转的。
- Charon 及小卫星暂无真实贴图，用真实反照率调制的灰阶占位球。
- 鼠标拖拽旋转视角，滚轮缩放；悬停出白描边，点击查看资料卡。
- 右侧面板的「**取景范围**」下拉可以切换镜头框到哪一层——卫星轨道跨度极大，一屏放不下全部，这是刻意的。
- 右上角「时间流速」可加速（天/秒）。点上方「全屏」按钮可铺满屏幕。
