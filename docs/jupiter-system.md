# 木星系统

木星与 **17 颗卫星**：内卫星 4 颗、伽利略卫星 4 颗、不规则卫星 9 颗。木星只做自转，卫星各自自转并公转。轨道半径、偏心率、倾角、升交点经度、周期全部取自 JPL 的**真实平均轨道根数**。

- **内卫星**：Metis / Adrastea 紧贴主环外缘，Amalthea 偏红且形状不规则，Thebe 界定了薄纱环外边界。倾角都不到 1.1°。
- **伽利略卫星**：Io（火山最活跃）→ Europa（冰下海洋）→ Ganymede（太阳系最大卫星）→ Callisto（最古老地表），由内到外周期从 1.77 天变到 16.7 天。
- **不规则卫星**：Themisto 单独一带；Himalia 群（Leda / Himalia / Lysithea / Elara，倾角约 28°）顺行；**Ananke / Carme / Pasiphae / Sinope 逆行**，倾角 148°–165°。
- Pasiphae 偏心率 0.412：近日点 1,380 万 km、远日点 3,313 万 km，轨道是一根很扁的椭圆。
- 最内到最外相差 **185 倍**，所以默认只框到伽利略卫星；换「+远距不规则卫星」档才看得到外圈。
- 鼠标拖拽旋转视角，滚轮缩放；悬停出白描边，点击查看资料卡。
- 右侧面板的「**取景范围**」下拉可以切换镜头框到哪一层——卫星轨道跨度极大，一屏放不下全部，这是刻意的。
- 右上角「时间流速」可加速（天/秒）。点上方「全屏」按钮可铺满屏幕。
