# 宇宙奇观 · 专栏概述

这个专栏收藏太阳系里的"离谱事实"：密度比水小的行星、躺着转的冰巨星、被降级的第九大行星。

每个天体都讲清三件事：**它是什么、为什么是这样、和地球比是什么概念**——所有距离、大小、温度、质量都换算成地球/月球/太阳参照系，拒绝干巴巴的裸数字。

## 收录方向

- **行星与矮行星** —— 从水星到柯伊伯带的个体档案
- **极端现象** —— 环系、冰下海洋、极端温度与风暴
- **尺度震撼** —— 一切数据都做"地球/月球/太阳参照系"换算
