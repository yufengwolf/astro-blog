# 海王星系统

- **海卫一 Triton 是唯一逆行公转的大卫星**：倾角 156.865°，方向与其他卫星相反。几乎可以肯定它是被捕获的柯伊伯带天体，表面还有活跃的氮气间歇泉。它的偏心率仅 0.000016——太阳系最接近正圆的轨道之一。
- 它的引力把原生内卫星系统搅得七零八落：7 颗内卫星真实轨道只差几千 km，彼此挨得极近（这里为了让它们可见把半径放大了，看着比真实更挤）。
- **海卫二 Nereid 偏心率 0.751**，远近海王星相差约 7 倍。
- 不规则卫星 Halimede / Psamathe / Neso 逆行，Sao / Laomedeia 顺行；Neso 距离近 5,000 万 km，绕一圈要 **26.8 年**。查看它们请切到「+不规则卫星」档。
- 鼠标拖拽旋转视角，滚轮缩放；悬停出白描边，点击查看资料卡。
- 右侧面板的「**取景范围**」下拉可以切换镜头框到哪一层——卫星轨道跨度极大，一屏放不下全部，这是刻意的。
- 右上角「时间流速」可加速（天/秒）。点上方「全屏」按钮可铺满屏幕。
