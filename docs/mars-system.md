# 火星系统

火星与它的两颗卫星——火卫一（福波斯）、火卫二（得摩斯）。火星只做自转，两颗卫星自转并绕火星公转，白色圆环为各自轨道。

- 两颗卫星都很小且形状不规则，很可能都是被火星捕获的小行星。
- 火卫一公转周期仅约 7.6 小时，比火星自转还快，因此在火星上看它「西升东落」。
- 卫星尺寸为了可视做了放大，并非真实比例。
