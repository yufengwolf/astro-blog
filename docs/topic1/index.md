# 观测指南 · 专栏概述

这个专栏回答一个最朴素的问题：**今晚我能看什么？**

不堆公式、不劝你买设备，从裸眼到双筒望远镜，把太阳系天体的观测时机、找星方法、预期效果讲成可执行的清单。

## 收录方向

- **观测时机** —— 大距、冲日、合日，哪天看哪颗星最好
- **找星方法** —— 星座定位、手机星图辅助、肉眼/双筒能看到什么
- **实拍预期** —— 不同设备下天体的真实观感，避免期待落空
