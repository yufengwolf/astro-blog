# 地月系统

地球与月球的独立 3D 子系统：地球只做自转，月球自转并绕地球公转，白色圆环为月球轨道。点击天体可飞近并查看资料。

- 月球轨道倾角约 5°，因此轨道面与地球赤道面并不重合。
