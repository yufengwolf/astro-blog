# 土星系统

土星与 **16 颗卫星**：牧羊犬卫星 2 颗、共轨道 2 颗、中层大卫星 7 颗、特洛伊卫星 3 颗、不规则卫星 2 颗。轨道参数全部为真实值，且 `distanceFactor = 1`——**轨道之间是完全真实比例**。

- **牧羊犬卫星** Prometheus / Pandora 一内一外夹着 F 环；**Janus 与 Epimetheus 共用同一条轨道**，每约 4 年互换一次内外位置——太阳系唯一的共轨道卫星对。
- **特洛伊卫星**：Telesto / Calypso 在土卫三轨道前后 60°，Helene 在土卫四前方 60°。
- **土卫八倾角 15.47°**，是土星大卫星里唯一明显倾斜的；切到「至土卫八」档才能看清它那条歪着的轨道。
- **土卫九 Phoebe 是逆行的**（倾角 151.78°），很可能来自柯伊伯带，被土星捕获。切到「+逆行的土卫九」档观看。
- 没画 Pan / Daphnis / Atlas：它们真实轨道埋在 A 环内部（低于 2.35 倍土星半径），画出来只会嵌进环贴图里看不见。
- 卫星暂无真实贴图，用真实反照率调制的灰阶占位球：土卫二几乎纯白（反照率 ~0.99），土卫六偏橙。
- 鼠标拖拽旋转视角，滚轮缩放；悬停出白描边，点击查看资料卡。
- 右侧面板的「**取景范围**」下拉可以切换镜头框到哪一层——卫星轨道跨度极大，一屏放不下全部，这是刻意的。
- 右上角「时间流速」可加速（天/秒）。点上方「全屏」按钮可铺满屏幕。
